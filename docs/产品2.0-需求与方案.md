# 产品 2.0 — 需求与实现方案（待确认后开发）

> 与现网（Git 静态题库 + 口令直登 + 多设备）并行开发，切换前不影响当前班级使用。

---

## 一、账号与设备

### 1.1 注册 / 审核（老师单人后台）

- 学生：提交 **虚拟昵称**（+ 班级口令）→ 状态 **待审核**，不能刷题。
- 老师：一个 **后台口令**（沿用 `admin_passphrase` 或独立 `teacher` 登录）→ 通过 / 禁用 / **删除**。
- **删除**：删 `profiles` 行，级联删除进度、错题、会话、章节成绩等（SQL `ON DELETE CASCADE`）。

### 1.2 单设备在线（不踢人）

- 每个 `active` 账号最多 **1 条有效会话**（`device_id` + `session_token` + 过期时间）。
- **先登录的设备** 保持有效；**后登录** 且 `device_id` 不同 → 提示 **「已在其它设备使用」**，拒绝创建新会话。
- 同一设备重新打开（相同 `device_id` 存 localStorage）→ 视为续期，允许。
- 刷题、同步、进门 API 均校验会话；过期后需在本机重新进门。

## 二、题库与老师录题

- **网页表单**（`/admin`），暂不做了 Excel/WPS 直传（可后续加导入）。
- 题型（首期）：
  - **单选题**：`answerIndex` 一个。
  - **多选题**：`answerIndices` 多个；判分 **全对才算对**（部分对不算，除非以后改规则）。
- 题目挂在 **章节 / 小节**（与现有人教版目录一致或后台可维护目录树）。
- 学生端：**从 Supabase 拉题 + 本地缓存**（离线策略二期可细化）。

## 三、刷题与打分（三条线）

### 3.1 当次练习分（不进排行榜）

- 学生进入一次练习（自选章节/筛选）→ 做题 → 点 **「结束练习」**。
- 仅统计 **本次会话内已作答的题目**：  
  `当次得分 = 当次做对题数 / 当次已做题数 × 100`（或展示百分制/十分制，UI 定）。
- 写入 `practice_sessions`（含明细），**不参与任何排行榜**。

### 3.2 章节榜（按章总分）— 已确认

- **完成条件**：该章 **每一道题都至少做过 1 次**（可跨多次练习、多天，不要求一次做完）。
- **章得分**（写入 `chapter_leaderboard_scores`，参与章排名）：  
  `章得分 = 做对题数 / 该章题目总数 × 100`  
  - **做对题数**：该章内 **至少有一次作答正确** 的题目数量（按 `question_id` 计，每题最多算 1 道对题）。
- **章节新增题目**：该生该章 **改回未完成**；章榜记录 **失效或下架**，直至 **含新题在内全部做过** 后 **重新生成** 章得分并再参与章排名。
- **章排名**：按章得分降序；同分可按 **重新完成时间** 先后（可选）。

### 3.3 总正确率榜（去重）

- 统计范围：学生 **历史上所有做过至少一次的题**（按 `question_id` **去重**）。
- `总正确率 = 至少做对过一次的题目数 / 至少做过一次的题目数 × 100`。  
  （同一题错 10 次后对 1 次 → 该题算 **对**；只对错从未对 → 算 **错**。）
- 与章节榜、当次练习分 **独立**。

## 四、老师后台能力（首期）

1. 录题 / 改题 / 删题（单选、多选）。  
2. 昵称 **待审核列表** → 通过 / 拒绝。  
3. 账号列表 → **禁用 / 删除**。  
4. 查看某生：**总正确率、章榜分、最近当次练习、错题本、进度单元**（后台账号列表 → **查看**）。

## 五、数据库表（概要）

| 表 | 用途 |
|----|------|
| `profiles` | +`status` pending/active/disabled |
| `profile_applications` | 可选，或合并在 profiles |
| `user_sessions` | 单设备会话 |
| `questions` | 题库 |
| `catalog_nodes` | 章/节树（或继续代码目录 + question 外键） |
| `practice_sessions` + `practice_session_answers` | 当次练习 |
| `user_question_state` | 每题是否做过、是否曾对过（供章完成与总正确率） |
| `chapter_leaderboard_scores` | 章完成后的上榜分 |
| `user_saved_state` | 错题本等（可保留） |

## 六、已确认规则（2026-09-30）

1. 章完成 = 章内 **每题都做过**；章分 = **做对题数 / 章总题数**（对题 = 该题至少做对过一次）。  
2. 章内 **加新题** → 该章 **未完成**，补做后 **重新计分上榜**。

## 八、P1 已落地（代码侧）

1. 执行 Supabase：`supabase/v2-p1-auth.sql`（或本机 `set -a && source .env && node scripts/apply-v2-p1.mjs`）。  
2. 设置 `app_secrets.admin_passphrase`（老师后台口令，与班级口令分开）。  
3. 学生端：进门页 **申请账号 / 登录**；登录走单设备校验。  
4. 老师后台：浏览器打开 **`https://你的站点/#/admin`**，输入后台口令 → 审核 / 禁用 / 删除。

> 执行 SQL 后，**旧账号** 默认 `status=active`；**新昵称** 需申请审核。现有 `kk` 等仍可直接登录（本机 device_id 绑定）。
