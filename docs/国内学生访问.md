# 国内学生打不开 Vercel 怎么办

`*.vercel.app` 在国内很多网络（尤其移动 5G、微信内置浏览器）会 **连接超时**，Vercel 后台显示 Ready 也打不开，这是 **域名被墙/不稳定**，不是部署失败。

## 方案 A：GitHub Pages（推荐先试，免费）

1. 打开仓库 **Settings → Pages**
2. **Build and deployment → Source** 选 **GitHub Actions**（不要选 Deploy from branch）
3. 等 `Deploy GitHub Pages` 工作流跑绿（约 2 分钟），或到 **Actions** 里手动 Run workflow
4. 把下面链接发学生（**用 Safari / Chrome 打开，不要只在微信里点开**）：

   **https://maolidong-ly.github.io/dili-shuati-test/**

5. （可选）在 **Settings → Secrets and variables → Actions** 里加 `VITE_SUPABASE_URL`、`VITE_SUPABASE_ANON_KEY`，再重新跑一次 workflow

> `github.io` 在国内也不是 100% 稳，但通常比 `vercel.app` 好不少。

## 方案 B：自有域名（国内长期用）

1. 购买域名（阿里云 / 腾讯云等）
2. 在 Vercel **Settings → Domains** 绑定，按提示配 DNS
3. 若仍慢，把静态资源迁到 **国内 CDN + 备案**（见方案 C）

## 方案 C：国内云静态托管（最稳，需备案）

适合「全班长期用、必须稳定」：

- 腾讯云 **静态网站托管 / COS + CDN**
- 阿里云 **OSS 静态网站 + CDN**

构建方式与 Vercel 相同：`npm run build`，上传 `dist` 目录。绑定已备案域名后，大陆访问最稳定。

## 使用习惯（减少打不开）

- 链接用 **系统浏览器** 打开，或「在浏览器中打开」
- 先 **添加到主屏幕**，以后从桌面图标进
- Supabase 在国外，弱网时同步可能慢；未配云库时仍可本地刷题（功能见产品说明）
